# True Aim Brand Guidelines (Retired)

**Retired (September 2026).** This document described the old "Ocean Blue" brand and is no longer accurate.
The brand moved to the **True Aim Design System**; see [`docs/DESIGN_SYSTEM.md`](DESIGN_SYSTEM.md) for the full,
current specification.

Below is a compact quick-reference for PowerPoint and Word documents, summarized from `DESIGN_SYSTEM.md` §3
(Colour tokens) and §4 (Typography). For anything beyond a slide or document, use the full design system doc.

## Quick reference

### Primary colours
| Colour | Hex | Use for |
|---|---|---|
| True Aim Blue (accent) | `#5151DB` | CTAs, links, key highlights, accent bars |
| Accent hover | `#4441C1` | Hover/darker accents |
| Light Blue | `#91A7FF` | Supporting highlight |
| Soft Lilac | `#F3EEFE` | Atmospheric backgrounds, icon plates |
| Primary Dark (heading text) | `#2C2B2A` | Headings, dark-band backgrounds |
| Primary Light (page background) | `#FBFCFD` | Slide/page backgrounds (light theme, default) |

### Semantic triads (status indicators only — never large surfaces)
| Status | Light | Base | Dark |
|---|---|---|---|
| Approved / success | `#7EE791` | `#1BB037` | `#0E6A20` |
| Referred / warning | `#FFCF8B` | `#FFAA36` | `#D37F0D` |
| Denied / error | `#FF8264` | `#E94119` | `#A92100` |
| In progress | `#ABBCF6` | `#5151DB` | `#37379C` |
| Help | `#D79DFF` | `#AA57E1` | `#6C19A4` |
| Neutral / disabled | `#CFCFD2` | `#84858C` | `#2C2B2A` |

### Fonts
Two fonts only: **Inter Tight** for titles/headings, **IBM Plex Sans** for everything else (body text, UI,
numbers use Inter Tight SemiBold with tabular figures for KPIs). No other typefaces.

### Shape
Filled containers (buttons, badges, chips, KPI/feature cards, icon plates) use a **40px pill radius**.
Sections and images stay square-cornered. Cards have no borders; use a subtle shadow instead.

### Brand name
In text, the brand is always **True Aim** (two words, capital T and A) — never "TrueAim", "TrueAIm", or
"True AIm". Legal entity: **True Aim AG**. The wordmark image/logo is the only exception.

### Tagline
**"Auditable by design."**
